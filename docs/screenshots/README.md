# Generic performance previews

The JPEGs in this directory capture the actual Performance, MIDI cue-builder and chord-voicing components in a browser preview using fictional songs and synthetic audio. Playback was paused, no MIDI port was connected, and sending was disarmed. These are illustrative UI captures, not evidence of hardware delivery or recognition accuracy.

- `performance-demo.jpg`: paused playlist, song key, mixer, combined reader and cue markers.
- `midi-commands-demo.jpg`: TimeLine channel 1, a named banked memory recall and scheduled cues.
- `chord-voicings-demo.jpg`: F major tabs in three barre positions.

The temporary preview entry point is not shipped with the app. Song text was written for the preview; no user music, preset names or device identifiers are shown.
